# Boardly — 产品与交互设计

## 1. 产品定义

Boardly 是一款面向个人用户的 macOS 原生人类待办看板。它帮助用户快速收集任务、明确下一步、限制正在进行的工作，并在一个安静的桌面空间里完成每日推进。

它不是团队项目管理系统，也不是 AI Agent 控制台。

### 核心承诺

> 打开应用的三秒内，用户能看清正在做什么、接下来做什么，并能立即记录一个新任务。

### 产品原则

1. **任务优先**：界面服务于任务阅读，不让装饰抢占注意力。
2. **原生优先**：使用菜单、快捷键、Inspector、拖放、撤销和系统搜索习惯。
3. **低维护**：首版只有一套稳定工作流，不让用户先设计自己的管理系统。
4. **本地优先**：无账号即可使用，启动快，离线完整可用。
5. **渐进展示**：卡片只显示决策所需信息，完整内容在 Inspector 中编辑。

## 2. 首版范围

### 包含

- Inbox、Today、Board 三个系统视图。
- 多项目与项目颜色，支持创建、重命名和删除；删除项目时关联任务回到 Inbox。
- 四列看板：Backlog、待办、进行中、已完成。
- 新建、编辑、删除、完成和恢复任务。
- 卡片跨列移动、列内排序，以及等价的菜单/键盘操作。
- 标题、备注、项目、状态、截止日期、优先级、标签、检查项。
- 搜索、项目筛选和隐藏已完成。
- 本地通知（只用于用户明确设置的到期提醒）。
- 深色首发外观、VoiceOver、减少动态效果。浅色外观作为后续可选项。

### 明确不做

- 定时自动生成任务、重复任务和后台执行器。
- 团队、成员、评论、权限和在线协作。
- Agents、技能、MCP、密钥、机器和模型服务。
- 甘特图、报表、工时、复杂依赖和自定义自动化。
- 首版自定义列与工作流编辑器。

## 3. 信息架构

```text
Boardly
├── Inbox                 未归类的新任务
├── Today                 今天到期或手动加入“今天”的任务
├── Board                 所有活跃任务的默认看板
├── Projects
│   ├── Personal
│   ├── Work
│   └── ...
├── Search                跨标题、备注、标签和项目
└── Settings
    ├── Appearance（后续提供跟随系统/浅色选项）
    ├── Notifications
    ├── Keyboard Shortcuts
    └── Data
```

项目点击后仍使用相同四列看板，只是自动限定到该项目。这样用户只学习一种空间模型。

## 4. 主窗口

### Sidebar

- 顶部显示应用名和侧栏收起按钮。
- 系统视图使用 SF Symbols 与文字：Inbox、Today、Board。
- Projects 区域显示颜色标记、名称和未完成数量。
- 底部仅保留设置入口；不放安装、账号或资源管理。
- 当前视图使用低饱和紫色 selection，不依赖文字变色判断选中状态。

### Toolbar

- 左侧：当前视图名称与任务数量。
- 中间：原生搜索字段，`⌘K` 聚焦。
- 右侧：筛选、Inspector 开关和唯一主按钮“新建任务”。
- 窄窗口时，筛选进入 overflow 菜单，主按钮保留。

### Board

- 四列水平排列，窗口不足时横向滚动。
- 每列头包含状态图标、名称、数量和添加按钮。
- 已完成默认显示最近完成项，并提供“显示全部”。
- 空列不使用大段插画，只显示一句说明和可执行入口。
- 在“进行中”列达到 3 项时显示柔和的 WIP 提示，但不强制阻止移动。

### Task Card

卡片默认只显示：

1. 标题，最多两行。
2. 项目色条与项目名称。
3. 临近/逾期日期、检查项进度等必要元数据。
4. 高优先级使用图标和文字提示，不能只使用颜色。

选中卡片后用边框和背景共同表示。Hover 只改变表面色，不位移卡片。

## 5. 任务详情 Inspector

Inspector 是主要编辑空间，宽度约 320–380 pt：

- 顶部：完成按钮、标题、更多菜单。
- 正文：可扩展备注编辑器。
- 属性：项目、状态、Today、截止日期、优先级、标签。
- 检查项：Return 新增，拖动排序，支持完整键盘编辑。
- 底部：创建时间和完成时间；删除任务放入更多菜单。

所有更改自动保存。关闭 Inspector 不应触发“是否保存”确认；只有尚未提交的新建任务 sheet 才需要防止误关。

## 6. 新建任务

- `⌘N` 打开紧凑 sheet，并立即聚焦标题。
- 当前项目和当前列作为默认值。
- 必填项只有标题；备注、日期和属性按需展开。
- Return 创建，`⇧Return` 在备注中换行，Escape 取消。
- 从 Inbox 新建时允许不选择项目。
- 创建成功后卡片短暂高亮，并提供 Undo。

## 7. 状态语义

| 状态 | 含义 | 默认入口 |
|---|---|---|
| Backlog | 值得保留，但尚未承诺近期执行 | Inbox 整理、主动移动 |
| 待办 | 已决定近期执行的下一步 | 新建任务、Today 规划 |
| 进行中 | 当前正在投入注意力 | 用户主动开始 |
| 已完成 | 已完成并保留历史 | 完成按钮或移动 |

完成任务时记录 `completedAt`；从已完成移出时清空完成时间。列顺序是稳定的产品语义，不在首版开放自定义。

## 8. 键盘与无障碍

| 快捷键 | 动作 |
|---|---|
| `⌘N` | 新建任务 |
| `⌘K` | 搜索 |
| `⌘1 / ⌘2 / ⌘3` | Inbox / Today / Board |
| `⌥⌘I` | 显示或隐藏 Inspector |
| `Return` | 打开选中任务 |
| `Space` | 快速预览 |
| `⌥← / ⌥→` | 将任务移动到相邻状态 |
| `⌘Z` | 撤销移动、完成或删除 |

VoiceOver 卡片摘要顺序为：标题、项目、状态、日期状态、检查项进度。拖拽不是唯一移动方式，右键菜单和快捷键提供等价能力。

## 9. 数据模型

```text
Project
  id, name, colorToken, sortOrder, isArchived

Task
  id, title, note, status, rank, projectID?
  isInToday, dueAt?, priority, createdAt, completedAt?

ChecklistItem
  id, taskID, title, isCompleted, rank

Tag
  id, name, colorToken
```

`rank` 独立于数组下标，支持跨列和列内重排。当前原型先使用原子写入的本地 JSON 保存，正式版本可迁移到 SwiftData；数据访问边界保持独立，为未来可选的 CloudKit 同步留出空间。

## 10. 后续版本候选

- 菜单栏 Quick Add。
- Apple Shortcuts、分享扩展和 Spotlight。
- CloudKit 私有数据库同步。
- 重复任务；只有真实用户需求出现时才加入。
- 可选 WIP 上限与归档策略。

不计划通过不断增加视图来竞争功能数量；后续功能必须缩短“捕获 → 选择 → 推进 → 完成”的路径。
